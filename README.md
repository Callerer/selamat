# Selamat
A platformer game in godot for Resolution-gamedev week5

## About
It follows a little white fella in a little wide world

## Details:
- I'm quite proud of this game. I made those walking and idle animations myself!
- I got to learn abt calling apis in godot
- It calls the random words api (<a href = "https://random-words-api.kushcreates.com"> Check here </a>), they're just used to create the atmosphere
